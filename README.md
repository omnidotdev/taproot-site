# Taproot Site

Marketing site for Taproot

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE.md)

</div>

## Overview

Taproot Site is the public-facing site for [Taproot](https://taproot.omni.dev), built with [TanStack Start](https://tanstack.com/start) and React.

## Prerequisites

- [Bun](https://bun.sh) 1.3+

## Development

```bash
bun i
bun dev
```

## Building

```bash
bun build
bun start
```
